# ARBOCK LABS — Independent Software & Applied AI Studio

Independent studio led by Guilherme Cavalcanti.

**We turn problems into working software.**

Site: https://lughlammas.github.io

This is the public repository for the ARBOCK LABS website: plain HTML, CSS and JavaScript, with no build step, in English and Portuguese.

The method is human-directed, AI-assisted development. Guilherme sets the objective and the acceptance criteria, assigns work to AI tools, inspects the result and decides what ships.

## Local preview

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Then open http://127.0.0.1:8080/.
