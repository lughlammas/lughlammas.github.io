Case: comercial-template

Template SaaS reutilizável para micro-ferramentas B2B. O primeiro recorte é um gerador de propostas comerciais (clientes, itens, totais, PDF).

Arquitetura

  • Next.js App Router + TypeScript + Tailwind
  • NextAuth (credentials + JWT)
  • Prisma + SQLite (Postgres documentado)
  • PDF com @react-pdf/renderer
  • Docker + .env.example

Papéis dos agentes

  • Produto: escopo B2B, landing, tabela de preços placeholder
  • Código: auth, CRUD, PDF, seed demo
  • QA: build, fluxo install → seed → demo
  • Docs: README, CLONE_PLAYBOOK, CUSTOMIZATION

Uso comercial

  • Base para clonar recibos, contratos, orçamentos
  • White-label: marca, domínio, tom de voz
  • Receita: instalação + personalização + manutenção
