SHERLOCK

What it is: a chess analysis environment. A React interface talks to a native chess engine only through a WebSocket controller and a UCI adapter; an Android build runs the engine as a native process. Tested: 8/8 parser and session tests passed (mocked engine output); typecheck clean. Not done: no CI; engine smoke tests not run; no strength or performance benchmark.

FLOWDESK · AI Operations Demo

What it is: a demo of an operations flow: form → rule-based triage → simulated reply suggestion → human approval → log, with signed webhooks, a private 24-hour sandbox per visitor and token-protected admin. Tested: unit, integration and browser tests passed on a local server; detailed counts are pending QA reproduction. Not done: local demo, hosting pending; no remote CI; axe and Lighthouse not run.
